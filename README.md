# Mini-SaaS

Projeto em desenvolvimento de um Mini-SaaS multi-tenant para oficinas mecânicas.

## Estrutura inicial

- `backend/`: aplicação Laravel
- `frontend/`: aplicação Nuxt 4
- `docker/`: arquivos de infraestrutura Docker
- `scripts/`: scripts utilitários
- `docs/`: documentação do projeto

## Stack

### Backend
- Laravel 12
- PHP 8.3+
- PostgreSQL
- Redis

### Frontend
- Nuxt 4
- Vue 3
- TypeScript
- Pinia
- SCSS
- Bootstrap 5
